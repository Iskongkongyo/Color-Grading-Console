## 🌟 项目简介

**调色台** 是一个纯前端、单文件运行的图片调色工具。

它可以把常见的“P图参数教程”做成可直接点击使用的滤镜配方，并通过 Canvas 在浏览器中实时预览效果。

不用安装软件，不需要后端，也不用上传图片到服务器。  
打开 HTML，就可以开始调色喵！ 🐱

---

## ✨ 功能亮点

- 🎨 内置多组调色预设，一键套用
- 🎛️ 支持手动调整光感、亮度、对比度、饱和度等参数
- 🌓 支持浅色 / 深色主题
- ↔️ 原图 / 效果拖动对比
- 🔍 PC 鼠标滚轮缩放，移动端双指缩放
- 🖼️ 支持点击、拖拽、粘贴导入图片
- 🧪 支持配置“示例图片”快速测试
- 💾 支持保存自己的调色预设
- 📦 支持预设 JSON 导入 / 导出
- 📤 支持按原始分辨率导出处理后的图片
- 📴 单文件运行，无额外依赖，可离线使用

---

## 🖼️ 使用方法

1. 打开 `调色台.html`
2. 导入一张图片，或者点击 **示例图片**
3. 在 **预设滤镜** 中选择喜欢的效果
4. 切换到 **手动参数** 继续微调
5. 拖动图片上的对比线查看原图 / 效果区别
6. 满意后点击 **导出图片**

就是这么简单。  
剩下的事情，交给你的审美和亿点点参数玄学。✨

## 🎛️ 支持参数

目前包含：

`光感` · `亮度` · `对比度` · `饱和度` · `锐化` · `高光` · `阴影` · `色温` · `色调` · `结构` · `纹理` · `颗粒`

部分预设还支持：

- 🌈 HSL 局部颜色调整
- 🎞️ 命名滤镜近似效果
- 🌸 滤镜强度控制
- 🧩 调整 Pipeline 步骤展示

## 🧪 示例图片

源码中可以直接修改：

```js
const EXAMPLE_IMAGE_SRC = './example.jpg';
```

支持相对路径和绝对链接，例如：

```js
'./images/demo.jpg'
'/assets/demo.jpg'
'https://example.com/demo.jpg'
```

推荐准备几张不同场景的测试图：

- ☁️ 白底 / 高调人物
- 👤 正常光线人像
- 🌳 蓝天绿树风景
- 🌃 夜景霓虹
- 🌇 日落逆光

这样更容易看出不同滤镜到底是真的好看，还是只在某一张图上“碰巧好看”。😼

## 💾 自定义预设

手动调好参数后，可以直接保存为自己的预设。

预设会优先保存在浏览器本地存储中，也可以通过 JSON 文件备份和迁移。

建议偶尔导出一份：

> 数据可以重调，灵感丢了就不一定找得回来了喵。📦

---

## ⚠️ 注意事项

- 使用远程图片作为示例图时，图片服务器需要允许 **CORS**
- 直接通过 `file://` 打开 HTML 时，部分浏览器可能限制本地图片的 Canvas 像素读取
- 超大分辨率图片导出会占用较多内存
- 内置命名滤镜为浏览器端近似模拟，并非对应 App 原始 LUT 的 1:1 复刻
